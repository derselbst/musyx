PIANOPAN

Piano stereo panning


Type: Pitch

Scale Centerkey Centerpan
0x0B PIANOPAN scale cen.key cen.pan

Description:

This macro command is especially designed to give instruments like a piano a naturalistic stereo behavior. The current key is used to calculate a pannning position. First, the key is converted to an offset by subtracting the cen.key. Next, the scale is applied. A scale of 127 will give you the full range, while a scale of 0 will eliminate any offset. Finally, the cen.pan is added. This last value can be viewed as teh position of the instrument in the room. Since the final values may exceed the normal panning range, illegal values are clipped. A negative scale will invert the stereo panorama.

Parameters:

scale = Scales the range of the panning.
cen.key = Defines the middle key of the panning.
cen.pan = Offset of the panning range (the center of the piano).
