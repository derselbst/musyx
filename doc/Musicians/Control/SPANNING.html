SPANNING

Sets the surround panning.


Type: Control

Pan Position Time ms Width
0x15 SPANNING pan.pos time width

Description:

Sets the surround panning to be used with the macro. If no panning is specified, the default front panning will be used. The pan.pos parameter specifies the position (0=Front, 64=Center, 127=Rear). The time and width parameters enable an automated pan-sweep. The panning will move from the specified location to the new one specified by the signed offset added to pan.pos within time milliseconds. If these parameters are zero, only the new panning position will be set.

Parameters:

pan.pos = Like MIDI-panning (0-127), where 0 is totally left, 64 is center and 127 is totally right.
time = Auto-panning slide time.
width = Offset to the pan position to which the auto-panning slides.
