ADDNOTE

Recalculate the current pitch by adding keysteps to the current key


Type: Pitch

Add Detune Org key ms switch Ticks/Millisec.
0x18 ADDNOTE add detune org.key ms flag ticks/ms

Description:

Recalculates the current pitch by adding add keysteps to the current key (or original key, if the org.key flag is set to ON) and applying the detune value in cents. The add parameter is a signed value. The last two parameters are zero by default. If tehy are non-zero values, they will be used in the same way as WAIT, to suspend the execution of the current macro for a given time interval.

Parameters:

add = Transposes the MIDI-key to a new note.
detune = Applies detune of +/-99 cents.
org.key = If set to ON, the original MIDI-key is used to calculate the new pitch.
ms flag = Switches the mode of the time parameter.
Ticks/Millisec. = Wait time specified in ticks or milliseconds. If 0, the macro proceeds directly to the next step
