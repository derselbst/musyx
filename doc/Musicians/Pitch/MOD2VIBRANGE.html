MOD2VIBRANGE

Modify vibrato range according to modulation input state.


Type: Pitch

Level note Level fine
0x22 MOD2VIBR keys cents

Description:

Sets up the key and cents range to use when the modulation input should influence the vibrato range. A range equal to zero will disable the scale of the vibrato range by the modulation input. The values are signed.

Parameters:

level = Level in note-steps (+/-12).
levelfine = Fine level (+/-99 cents).
