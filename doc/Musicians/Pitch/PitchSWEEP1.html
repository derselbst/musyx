PitchSWEEP1

Add a sweep to the pitch.


Type: Pitch

Times Add ms switch Ticks/Millisec
0x1D PitchSWEEP1 times add-value ms flag ticks/ms

Description:

Adds the add-value n-times to the current pitch. After this, the action starts again at the original pitch. To stop the effect, set add to zero. The last two parameters are zero by default. If they are non-zero values, they will perform the same as in WAIT, to suspend the execution of the current macro for a given time interval. There are actually two commands of this kind, PitchSWEEP1 and PitchSWEEP2. They work independently of each other, but combine to perform very nice effects if used simultaneously.

Parameters:

times = Defines the number of frames to which add-value is applied.
add-value = The value to be added to the pitch per frame.
ms flag = Switches the mode of the time parameter.
ticks/ms = A wait time specified in ticks or milliseconds. If equal to zero, the macro proceeds directly to the next step.
