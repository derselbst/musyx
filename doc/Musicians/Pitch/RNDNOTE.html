RNDNOTE

Set random pitch.


Type: Pitch

Note Lo Detune Note Hi Fixed/Free Abs/Rel
0x17 RNDNOTE note-lo detune note-hi fix/free abs/rel

Description:

Sets random pitch. Note-lo is the lower end of the range and note-hi is the upper end. The detune value, specified in cents, is added after the random pitch is calculated, but only if the fix/free flag is set to OFF. If the fix/free flag is set to ON, the pitch will be generated freely inside the range without respect to any key steps. If rel/abs is set, note-lo specifies how many keys below the current key the range should start, while note-hi defines the size of the upper range.

Parameters:

note-lo = Lower end of the range.
detune = Applies a detune after the note is calculated.
note-hi = Upper end of the range.
fix/free = OFF = the random pitch is quantized to note values.
ON = the pitch is calculated freely within the range.
