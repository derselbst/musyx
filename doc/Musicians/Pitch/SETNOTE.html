SETNOTE

Set note by a fixed key.


Type: Pitch

Key Detune ms switch Ticks/Millisec.
0x19 SETNOTE key detune ms flag ticks/ms

Description:

Calculates a new pitch by setting the current key to the new value specified by key, then applies the detune value, specified in cents. The last two parameters are zero by default. If tehy are non-zero values, they will be used in the same way as WAIT, to suspend the execution of the current macro for a given time interval.

Parameters:

key = A fixed key in the normal MIDI key range (0-127)
detune = Applies detune of +/-99 cents.
ms flag = Switches the mode of the time parameter.
Ticks/Millisec. = Wait time specified in ticks or milliseconds. If 0, the macro proceeds directly to the next step.
