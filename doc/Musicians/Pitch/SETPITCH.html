SETPITCH

Set the pitch directly


Type: Pitch

Freqyency in Hz Fine
0x1F SETPITCH Hz (24 bit) fine

Description:

Directly sets the frequency to be used to playback a sample. This should be used immediately after STARTSMP, since the system needs to know the sampl's properties to correctly calculate the pitch.

Parameters:

Hz = The coarse frequnecy in HZ (0-88200)
fine = A fine resolution parameter (0-65536)
