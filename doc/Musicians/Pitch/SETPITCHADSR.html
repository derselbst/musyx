SETPITCHADSR

Activate pitch ADSR


Type: Pitch

DLS-type ADSR Note range Cents
0x20 PITCHADSR Table ID keys cents

Description:

Sets and activates a pitch ADSR. The maximum pitch change is specified by the keys and cents parameters. Both are signed values to allow for pitch ADSR's ascending and descending. The table referenced by table ID has to be a DLS-type ADSR definition.

Parameters:

Table ID = ID of table containing a DLS type ADSR definition.
keys = Signed value indicating the maximum range of the pitch ADSR.
cents = Signed value indicating the maximum range of the pitch ADSR.
