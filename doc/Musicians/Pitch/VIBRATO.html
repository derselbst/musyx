VIBRATO

Adds a vibrato to the voice currently used to play the macro.


Type: Pitch

Level note Level fine Modwheel flag ms switch Ticks/Millisec.
0x1C VIBRATO level levelfine mod. ms flag ticks/ms

Description:

Adds a vibrato to the voice currently used to play the macro. Vibrato means that the pitch is modulated by a sine waveform with a period specified by ticks. If the ticks/ms flag is set, the period is given in milliseconds instead. A period of zero will disable the vibrato. The number of keysteps that it should go up or down gives the amplitude of the waveform. The level parameter is a signed value. If it is negative, the pitch offset will go down first. If it is positive, the offset will go up first. Levelfine is specified in cents. If mod. is set to ON, the values from the modulation input will be used to scale the vibrato. An OFF value disables any scaling by that input.

Parameters:

level = Level in note-steps (+/-12).
levelfine = Fine level (+/-99 cents).
mod. = An ON value scales teh level with the modulation input.
ms flag = Switches the ticks/ms parameter from ticks to milliseconds.
ticks/ms = Specifies period time in either ticks or milliseconds.
