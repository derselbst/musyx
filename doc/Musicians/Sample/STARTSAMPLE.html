STARTSAMPLE

Start a sample


Type: Sample

Sample-ID Vel. Scale Sample Start Offset
0x10 STARTSMP smpID Mode Sample Start Offset

Description:

Starts the playback of the sample specified by smpID. An offset inside the sample may be specified, but is not supported on all hardware platforms (e.g., Startsample playing from offset is not supported on GameBoy). If it is supported, it is always specified in samples, not bytes. If no ADSR is previously specified, a standard ADSR is used. It avoids click-sounds as much as possible, but starts and stops the sample almost immediately.

Note: Only PCM samples support the full range of offsets at the full resolution. ADPCM+ supports all modes, but aligns the start offset to block boundaries (14 samples). ADPCM does not support any offset different from zero.

Parameters:

smpID = The ID of the sample to be started.
mode = Defines offset mode.

Mode Description
0 Apply offset directly
1 scale offset with negative velocity (higher velocity results in smaller offset).
2 scale offset with positive velocity (higher velocity results in higher offsets.

offset = The offset in sample-units. If mode = 1 or 2, the offset defines the maximal range.
