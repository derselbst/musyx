GET_MESSAGE

Get message received by macro.


Type: Setup

Variable
0x2B GET_MESG var ID

Description:

Retrieves message received by the current macro and stores the value in the variable indicated by Var ID. If no message was received, the value will be 0. A 4-entry deep FIFO is available to receive multiple messages at once.

Parameters:

Var ID = ID of variable to receive the message's value.
