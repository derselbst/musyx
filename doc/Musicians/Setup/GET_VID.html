GET_VID

Get voice ID of a voice.


Type: Setup

Variable Mode
0x2C GET_VID var ID flag

Description:

Gets VID of either the current voice (flag = 0), or the voice started by the last PLAY_MACRO command (flag = 1).

Note: Variables are normally treated as 16-bit values, but a VID is a 32-bit value. Arithmetic operations on VID's are not only making little sense, but actually have undefined results. You may use IF_EQUAL to compare VID's, though.

If no VID is returned, a VID-error value of 0xFFFFFFFF will pass back. This value, although not identifying any specific voice, can be used with any other command or API function using VID's.

Parameters:

Var ID = ID of variable to receive the message's value.
