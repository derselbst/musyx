MODE_SELECT

Set global system modes.


Type: Setup

DLS Vol. ITD
0x58 MODE_SELECT DLS ITD

Description:

Enables or disables global states for the current voice. The DLS flag determines whether the MusyX volume curve (0) or the original DLS curve (1) should be used. The ITD flag determines whether ITD (initial time delay) is enabled (1) or disabled (0) for this voice.

Parameters:

DLS = Dteremines volume curve to use (0=MusyX, 1=DLS).
ITD = Determines ITD state (0=OFF, 1=ON).
