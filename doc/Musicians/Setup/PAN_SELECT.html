PAN_SELECT

Add a panning calculation component.


Type: Setup

MIDI Contr. Scale Percentage Combine uCode Var. Input Fine Scale
0x41 PAN_SELECT ctrl scale comb var fine

Description:

Selects an additional component for the panning calculation. The first use of this command resets the default values to empty and adds the new component. All further calls add addtional components. Comb=0 sets the value, comb=1 adds the value, and comb=2 multiplies the old and new values.

Parameters:

ctrl = The MIDI controller number/variable index (see below).
scale = A signed factor (-100000 to 10000) in percent.
comb =
Value Description
0 set value from defined controller.
1 add value to current controller assignment.
2 multiply the old and new controllers.
var =
Value Description
0 ctrl specifies a MIDI controller number.
1 ctrl specifies a variable.
fine = An unsigned scaling factor (0 to 100 in percent with 1/100th percent steps (applied together with the scale parameter)).

You may use all standard MIDI controller numbers, as well as the defined extensions detailed under VOL_SELECT.
