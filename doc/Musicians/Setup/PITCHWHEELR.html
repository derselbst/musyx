PITCHWHEELR

Set the number of keysteps for calculating pitchwheel range.


Type: Setup

Range up Range down
0x33 PITCHWHEELR rng up rng dwn

Description:

Sets the number of keysteps used to calculate the pitchwheel range. The size of the lower and the upper range can be selected seperately. The default value is two keysteps for both ranges.

Parameters:

rng up = The positive range in key steps.
rng dwn = The negative range in key steps.
