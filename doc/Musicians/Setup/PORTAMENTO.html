PORTAMENTO

Set portamento mode and time.


Type: Setup

Port. State Port. Type ms switch Ticks/millisec.
0x1B PORTAMENTO state type ms flag ticks/ms

Description:

Sets up the mode for a portamento operation. Setting state equal to 0 will disable portamento, while setting state equal to 1 enables it. A value of 2 keeps the state unchanged. By default, portamento is controlled by the MIDI portamento controller (65). The time parameter controls the time needed to reach the current key. By default, this is 500ms. Type defines the type of portamento function. A value of 0 performs portamento only if the last key is still depressed, while a value of 1 performs it all the time. A legato function can be achieved by setting the time parameter to 0.

Parameters:

mode = Sets portamento mode.

mode value Description
0 OFF
1 ON
2 MIDI controller (65) controls OFF/ON

type = Portamento type.

Type ID Description
0 enable portamento when old key is held while new key is pressed.
1 portamento always active.

ms flag = Switches the ticks/ms parameter from ticks to milliseconds.
ticks/ms = Specifies portamento time in either ticks or milliseconds.
