SEND_MESSAGE

Send message to macro or voice.


Type: Setup

Mode Target ID Var ID Message
0x2A SEND_MESG flag ID Var ID 1 Var ID 2

Description:

Sends a numerical value to another voice or type of macro. Flag controls the manner in which the target of the message is specified. If 0, the ID parameter will be used to identify a macro ID which should receive the message. All active macros of this type will receive the message. If 1, the Var ID1 parameter is used to identify a variable which contains a VID that identifies a single voice (and its children) as target for the message.

The value send to the target is specified by Var ID.

Messages may be sent to the application (which has to register a callback) by using the "macro mode" and a macro ID of 0xFFFF.

Parameters:

flag =
Value Description
0 ID parameter is macro ID
1 ID parameter is variable ID
ID = macro ID (if mode 0).
Var ID1 = ID of variable containing a VID (if mode 1).
Var ID2 = ID of variable containing value to be sent.
