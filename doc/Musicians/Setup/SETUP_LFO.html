SETUP_LFO

Set up LFO characteristics.


Type: Setup

LFO Nr. Period in ms
0x50 SETUP_LFO num period

Description:

Enables or disables the specified LFO. A period value of 0 will disable the LFO. From that point on, it will continue to produce the last value as a constant. The LFO always starts at center level, unless it was already active. Num specifies which LFO should be set up. Currently two LFO's (0 and 1) are supported.

The LFO's always swing through the full amplitude. Use the scale parameter when combining them, using the x_SELECT macro commands to control the amplitude.

The following table shows how to access the two LFO's in combination with any of the x_SELECT macro commands:

ExCTRL Function
130 LFO1
131 LFO2
