SET_KEYGROUP

Define keygroup to be used for the current voice.


Type: Setup

Key Group Kill Mode
0x59 KEYGROUP ID flag

Description:

By default, a voice does not belong to any keygroup. SET_KEYGROUP puts the voice into a keygroup and defines what happens to all other active voices that belong to this keygroup. An ID value of 0 indicates that no keygroup should be used; this value can be used to remove a voice from a keygroup.

Keygroups are simply defined by an 8-bit numerical value. Each time a voice is assigned to a keygroup. All such detected voices will either be switched off immediately (kill mode =1) or sent a keyoff signal (kill mode=0). For example, this allows you to ensure that all hi-hats in a drum set behave as if they were actually a physical unit (i.e., any playing open hi-hat will be stopped immediately if a closed hi-hat is played).

Parameters:

ID = ID representing a volume group (0 = none)
flag =
Value Description
0 Sends keyoff to all members of the group.
1 Switches voices off.
