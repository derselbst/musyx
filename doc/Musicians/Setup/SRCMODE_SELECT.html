SRCMODE_SELECT

Set SRC mode for this voice.


Type: Setup

SRC Coef.
0x5A SRCMODE_SELECT type tabindex

Description:

Change the SRC type and parameters to be used for this voice. Influencing the SRC can have a tremendous impact on the frequency spectrum of the resampled output. You may select between three different SRC types: polyphase, linear, and none.

All voices use polyphase resampling and the 12.8KHz filter setting by default. This is comparable to the Nintendo 64 (N64) audio system.

Parameters:

type = SRC type

Value Description
0 Polyphase (N64 style). Use tabindex to set the filter.
1 Linear
2 None (i.e., no resampling will take place; the sample will always play at the system's mixing frequency).

tabindex = Sets the filter to be used.

Value Description
0 8KHz
1 12.8KHz
2 16KHz
