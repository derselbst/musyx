VOL_SELECT

Add a volume calculation component.


Type: Setup

MIDI Contr. Scale Percentage Combine uCode Var. Input Fine Scale
0x33 VOL_SELECT ctrl scale comb var fine

Description:

Selects an additional component for the volume calculation. The first use of this command resets the default values to empty and adds the new component. All further calls add additional components. Comb=0 sets the value, comb=1 adds the value, and comb=2 multiplies the old and the new values.

Parameters:

ctrl = The MIDI controller number/Variable index. (see table below)
scale = A signed scaling factor (-10000 to 10000) in percent.
comb =

mode value Description
0 set value from defined controller.
1 add value to current controller assignment.
2 multiply the old and new controllers.

var =

mode value Description
0 ctrl specifies a MIDI controller number.
1 ctrl specifies a variable.

You may use all standard MIDI controller numbers, as well as the following defined extensions:

ExCTRL Function
128 Pitchbend (since there is no controller in the MIDI standard)
129 Aftertouch (since there is no controller in the MIDI standard)
130 LFO1 (see SETUP_LFO macro command.)
131 LFO2 (see SETUP_LFO macro command.)
132 Surround Panning (0=front, 127=surround)
133 Key used to start macro
134 Velocity used to start macro
135 Time [ms] since macro start (only 14-bit!)
