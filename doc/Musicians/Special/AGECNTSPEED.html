AGECNTSPEED

Set age-counter speed


Type: Special

Time Until Zero
0x38 AGECNTSPEED time

Description:

Changes the speed of the age-counter decrement. By default, the counter will reach zero after about 18 minutes. The time value sets the number of milliseconds the counter will need in order to decrement to zero from its current value. If time is set to zero, the priority counter will not be changed over time at all.

Parameters:

time = The time (0-1080000) in milliseconds to reach 0.
