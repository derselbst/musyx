AGECNTVEL

Set the age-counter using velocity.


Type: Special

Age Base Age Scale
0x39 AGECNTVEL AGE Base AGE Scale

Description:

Sets the age-counter of the current voice, calculated from a base number and the MIDI velocity, to allow customized priority handling.

Parameters:

AGE Base = Age base value (0-65535).
AGE Scale = Scaling factor for the velocity (0-65535) to be added.
