MUL_VARS

Multiply variables.


Type: Special

Ctrl A= Ctrl B Ctrl C
0x62 MUL_VARS Var/Ctrl A Var/Ctrl B Var/Ctrl C

Description:

Multiplies the current values of variables B and C and stores the result in variable A. The Var/Ctrl switches select whether a variable or a controller should be accessed. If a switch is set to ON, the corresponding value index is used as an extended controller number.

Parameters:

Var/Ctrl = Controller A switch (OFF = Variable, ON = extended controller).
A = Variable / Controller A
Var/Ctrl = Controller B switch (OFF = Variable, ON = extended controller).
B = Variable / Controller B
Var/Ctrl = Controller C switch (OFF = Variable, ON = extended controller).
C = Variable / Controller C
