SET_VAR

Set variable to immediate value.


Type: Special

Ctrl A= Imm
0x65 SET_VAR Var/Ctrl A Immediate

Description:

Replaces the current value of variable A with the specified immediate value. The Var/Ctrl switch is set to ON, the value index is used as an extended controller number.

Parameters:

Var/Ctrl = Controller A switch (OFF = Variable, ON = extended controller).
A = Variable / Controller A
immediate = Immediate value to add to B.

See also:

ADD_VARS for details on variables
