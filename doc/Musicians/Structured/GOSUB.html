GOSUB

Jump to another macro.


Type: Structure

SoundMacro ID SoundMacro step
0xXX GOSUB Macro Step

Description:

Performs an unconditional jump to the specified location. In contrast to GOGO, the position of the next command in the macro will be put on a "call stack." The RETURN command can be used to continue execution at that position.

Parameters:

macro = The target macro ID.
step = The step inside the specified target macro.
