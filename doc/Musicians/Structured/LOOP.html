LOOP

Loop back to a macrostep.


Type: Structure

Keyoff Random Sampleend SoundMacro Step Times
0x05 LOOP key release random sample end step times

Description:

Loop to the specified location within the current macro n-times. If one of the flags is set, the loop may execute less than the specified number of times. A value of 0xFFFF (65535) will cause an endless loop. Loops may not be nested.

Parameters:

key release = If set to on and a keyoff is recived, the command will not
loop but instead proceed with the next step in the macro.
random = If set to on, the command will loop a random number of times
where the timesparameter specifies the maximum count of loops.
sample end = If set to on the command will not loop when the sample reaches
its end (note that this works only with one-shot samples).
step = This defines the macrostep to which the command loops.
times = The number of loops to be performed. A times value of 0xFFFF
(65535) will cause an endless loop, if none of the other conditions apply.
