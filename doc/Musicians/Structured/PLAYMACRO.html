PLAYMACRO

Starts another macro.


Type: Structure

Addnote SoundMacro ID SoundMacro step Priority Max Voices
0x08 PLAYMACRO Addnote macro step priority maxVoc.

Description:

Starts another macro in parallel to the current one. Since this macro starts like any other macro, the normal delays, etc., apply. The macro will be passed the priority and the maxVoc. values specified. The key is calculated by adding addnote to the original key of the macro starting the new one. The new macro may be started at any macrostep, using the step parameter.

Parameters:

addnote = A keyshift or transpose value (-128 to 127) can be added to start the new voice with a different note.
macro = The ID of the new macro to start.
step = The step inside the new macro to start.
priority = The priority definition of the new voice.
maxVoc. = The maximum count of voices that this new macro can allocate.
