SENDKEYOFF

Send a keyoff to the specified macro.


Type: Structure

Variable Last Started
0x09 SENDKEYOFF Var ID Last

Description:

Sends a keyoff to the specified voice. The variable specified by Var ID must contain a valid VID. VIDs can be received by using GET_VID or the VID resulting from the last PLAY_MACRO command can be used implicitly by setting last to 1. Note that it is perfectly valid to pass the VID-error value as a VID. The SENDKEYOFF command will be treated as a NOP in that case.

Parameters:

Var ID = The ID of a variable contianing the VID of the target voice.
