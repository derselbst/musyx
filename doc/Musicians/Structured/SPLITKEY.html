SPLITKEY

Splits the macro flow depending on the MIDI key.


Type: Structure

Keynumber SoundMacro ID SoundMacro Step
0x02 SPLITKEY key macro step

Description:

This command is used to change the flow of execution conditionally in the current macro. The macro program will jump to the given macrostep inside the specified macro, if the current key is higher than or equal to the key parameter.

Parameters:

key = This parameter specifies a key number (0-127) to compare
against. If the key you play is higher or the same as this key, the
macro will jump, otherwise it resumes.
macro = The ID of the target macro
step = The step number inside the target macro.
