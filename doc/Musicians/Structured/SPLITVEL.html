SPLITVEL

Splits the macro flow depending on the velocity.


Type: Structure

Velocity SoundMacro ID SoundMacro Step
0x03 SPLITVEL velocity macro step

Description:

This command is used to change the flow of execution conditionally in the current macro. The macro program will jump to the given macrostep inside the specified macro, if the current key is higher than or equal to the key parameter.

Parameters:

velocity = Specifies the velocity against which to compare the current velocity.
If the current velocity is higher or the same, the macro will jump to the
target macro; otherwise it will resume.
macro = The ID of the target macro.
step = The step number inside the target macro.
