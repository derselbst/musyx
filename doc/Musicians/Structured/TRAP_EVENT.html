TRAP_EVENT

Registers a jump destination in a macro.


Type: Structure

Event SoundMacro ID SoundMacro step
0x28 TRAP_EVENT Event ID macro step

Description:

Registers a jump destination in a macro if the specified event occurs

Parameters:

Event ID = The Event ID triggers the trap

Event ID Description
0 Keyoff received by macro.
1 Sample ended.
2 Message received by macro.

macro = The ID of the new macro to start.
step = The step inside the new macro to start.
