WAIT_MS

Wait, depending on various conditions.


Type: Structure

Keyoff Random Sampleend Abs Switch Millisec.
0x07 WAIT_MS key release random sample end absolute ms

Description:

The execution of the current macro will be suspended until the given time has elapsed. The time is specified in milliseconds. If the absolute switch is set, the time value is no longer specified relative to the current time, but relative to the time at which the macro began execution. A value of 0xFFFF (65535) will cause an endless wait.

If one of the other flags is set, execution will resume as soon as one of the corresponding conditions becomes true or the given time has elapsed.

Parameters:

key release = If this flag is set, the macro will resume after receiving a keyoff.
random = If this flag is set, the macro will resume after a random time has elapsed. In this case, the ticks/millisec. parameter defines the maximum wait time.
sampleend = If this flag is set, the macro will resume when the sample reaches its end (note that this works only with one-shot samples).
ms = The wait time specified in milliseconds.
