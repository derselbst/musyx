WAIT_TICKS

Wait, depending on different conditions.


Type: Structure

Keyoff Random Sampleend Abs switch ms switch Ticks/millisec.
0x04 WAIT_TICKS key release random sample end absolute ms flag time

Description:

TThe execution of the current macro will be suspended until the given time is elapsed. By default, the time is specified in ticks. If the ms flag is set, the time will be specified in milliseconds. If the absolute switch is set, the time value is no longer specified relative to the current time, but relative to the time at which the macro began execution. Independent of the selected time format, a value of 0xFFFF (65536) will cause an endless wait.

If one of the other flags is set, execution will resume as soon as one of the corresponding conditions becomes true, or the time given has elapsed.

Parameters:

key release = If this flag is set, the macro will resume after receiving a keyoff.
random = If this flag is set, the macro will resume after a random amount of time has elapsed.
In this case the ticks/millisec. parameter defines the maximum wait time.
sampleend = If this flag is set, the macro will resume when the sample reaches its end
(note that this works only with one-shot samples).
ms flag = This flag switches the mode of the time parameter.
Ticks/millisec. = The wait time specified in ticks or milliseconds.
