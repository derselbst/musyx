FADE-IN

Start a software fade-in envelope.


Type: Volume

Scale Add Table-ID (Curve) ms switch Ticks/Millisec.
0x14 FADE-IN Scale Add Table ms flag ticks/ms

Description:

Starts a software fade-in envelope. Fades the velocity of the current macro from zero to the new velocity in the time specified by ticks/ms. If ms flag is set, the time will be marked in milliseconds instead of ticks. The new volume is calculated the same way as in SCALEVOLUME.

Parameters:

scale = The scaling factor of the velocity.
add = A fixed offset that can be added to the velocity. Applies clipping if the result exceeds 127.
table = Table ID of a volume translation curve (0=linear).
ms flag = Switches the tics/ms parameter from ticks to milliseconds.
ticks/ms = Specifies fade time in either ticks or milliseconds.
