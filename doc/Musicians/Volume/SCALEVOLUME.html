SCALEVOLUME

Scale the velocity to calculate a new volume for the current voice.


Type: Volume

Scale Add Table-ID (Curve) Org Vol.
0x0D SCALEVOLUME Scale Add curve org. vel

Description:

Calculates a new volume for the current voice by scaling the velocity. The velocity is passed to the macro either by the sequencer (via MIDI), or by the effect handler. A scale of 127 equals 100%. Smaller values scale down and larger values scale up. In addition to the simple scale, an offset can be specified in the add parameter. The result of this calculation can be passed through a curve that will act as a translation table (a value of zero in the curveparameter will disable this feature). The new volume is calculated using either the current velocity (org.vel=0) or the original velocity (org.vel=1).

Parameters:

scale = The scaling factor of the velocity.
add = A fixed offset that can be added to the volume.
curve = Table ID of a volume translation curve (0=linear).
org.vel = If this switch is set to ON, the initial velocity that was set when the
macro was started is used instead of the current velocity/volume.
