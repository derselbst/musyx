SCALEVOLUME_DLS

Scale current volume of voice suitable for DLS operation.


Type: Volume

Scale Org Vol.
0x21 SCALEVOL_DLS Scale org. vel

Description:

Calculates a new volume for the current voice by scaling the velocity. A scale of 4096 equals 100%. The new volume is calculated either using the current velocity (org.vel=0) or the original velocity (org.vel=1).

Parameters:

scale = The scaling factor of the velocity.
org.vel = If this switch is set to ON, the orignal velocity (the one from when the macro was started) is used instead of the current velocity/volume.
