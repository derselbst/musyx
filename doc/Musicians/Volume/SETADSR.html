Type: Volume

Table-ID (ADSR) Type
0x0C SETADSR Table TypeID

Description:

The data from the specified table define an ADSR to be used with the voice. The editor presents a graphical edit dialog to define tables containing the needed data if it is a MusyX-type ADSR.

Parameters:

table = This references the ID of the table that contains the ADSR.
typeid = Defines the ADSR type.

Type Description
0 MusyX linear ADSR
1 exp. DLS type ADSR
