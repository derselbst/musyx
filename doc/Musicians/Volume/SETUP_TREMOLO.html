SETUP_TREMOLO

Control the tremolo effect.


Type: Volume

Scale Mod. Scale
0x23 TREMOLO Scale Scale

Description:

Sets up tremolo effect. The scale parameter defines the level to which the volume should be decreased at maximum during the tremolo LFO process. The mod.scale parameter controls an additional offset that will be added (when thinking in "dB space") according to the state of the modulation input. If that input is zero, no offset will be added; if it is full (0x3FFF), the complete specified offset will be added. The scale used to influence the volume is calculated as follows:

First, the mod.scale is transformed according to the state of the modulation input (e.g., 100% will be used if the modulation input is zero and the specified value will be used if the modulation is maximized). The scale is determined by the tremolo input (which should be connected to either LFO0 or LFO1 first - please not that it is best to use a phase of 180 degrees as start offset for the LFO's when using temolo to avoid any click sounds). Finally, both modified scales are multiplied with each other and the result is applied to the current volume. Please note that the current volume is only modified momentarily. The actual value accessible to the macro does nto change. A scale of 4096 equals 100% for all parameters. If both scales are 0, the tremolo effect will be switched off.

Note: Future versions of the editor will abstract thsi to use dB attenuation values.

Parameters:

scale = The "main" scaling factor of the volume.
mod.scale = The "modulation" scaling factor of the volume.
