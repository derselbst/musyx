sndAddEmitterEx

SND_VOICEID sndAddEmitterEx(SND_EMITTER *em_buffer, SND_FVECTOR *pos, SND_FVECTOR *dir, f32 maxDis, f32 comp, u32 flags, SND_FXID fxid, u16 groupid, u8 maxVol, u8 minVol, SND_ROOM *room);

Purpose:

This function adds an emitter structure to the list of emitters. Emitters are added to the default studio. The caller specifies a room to which the emitter must be added, but this feature is not supported at this time, and the value must be set to NULL.

SND_EMITTER *em_buffer
Pointer to a sturcture defining the parameters of the emitter to be added. SndAddEmitterEx() initializes all values in this structure. The structure is not copied by the function and must be kept around as long as the emitter is active.

SND_FVECTOR *pos
Pointer to a vector containing the initial position of the emitter.

SND_FVECTOR *dir
Pointer to a vector containing the initial movement direction of the emitter.

f32 maxDis
Maximum distance at which the emitter will still be audible.

f32 comp
This is a value between -1.0 and 1.0. For values near -1.0, the volume of the emitter will remain low while the emitter is far away from the listener, then increase exponentially only when the emitter is very close to the listener. For values near 0.0, the volume of the emitter will be attenuated linearly with respect to the distance between the emitter and the listener. For values near 1.0, the volume of the emitter will be high while the emitter is close to the listener, then decrease exponentially only when the emitter is very far from the listener.

u32 flags
The following flags are defined to influence the emitter behavior:

SND_EMITTER_DEFAULT
No special features are activated. This flag is appropriate if the "SND_EMITTER *em_buffer" parameter is NULL.

SND_EMITTER_CONTINUOUS
Updates parameters contiuously. If this is not set, the volume, panning and Doppler values will only be calculated at the start of the emitter. The alternate spelling SND_EMITTER_CONTINOUS may be used to achieve the same effect.

If the parameter "SND_EMITTER *em_buffer" is NOT a NULL pointer, then this flag must be asserted.

SND_EMITTER_RESTARTABLE
The SFX handled by the emitter may be restarted after being stopped for any reason. For example, this can be used to reactivate an engine hum after an explosion has interrupted it for a short time.

SND_EMITTER_PAUSABLE
If the emitter is no longer in the audible range it may be stopped. If this flag is not set, the SFX will remain active although its volume is all the way down. This may be necessary to run long-duration sound effects.

SND_EMITTER_DOPPLERFX
If this flag is set, the emitter will be included into the Doppler effect calculations of all listeners that have Doppler calculations enabled.

SND_EMITTER_ITD
All sound effects, and therfore all emitters, have ITD disabled by default. This flag will enable ITD for this emitter. Keep in mind that the macro controlling the sound may overwrite this setting.

SND_FXID fxid
ID of the SFX to be used by the emitter.

u16 group
An arbitrary, user-assigned value for grouping emitters together. Emitters within a group will contend for available voices based on their respective volumes and age (how long they have been audible). The group ID specifed here has nothing to do with the groups used to push or pop data from the sound stack. Emitters of different groups will contend for voices through the normal priority system. This value must be an integer between 0 and 65535.

u8 minVol
Volume to be used at maximum audible range.

u8 maxVol
Volume to be used at the postition of the listener.

SND_ROOM *room
A pointer to a structure that describes a room's properties. Currently not supported, this value should be set to NULL.

Output:

Returns a handle to the SFX started by the emitter. This value may be SND_ID_ERROR without any failure. The start of continuous emitters may be delayed by an audio frame or two, sometimes.

Note that if you attempt to start an emitter with the same sound effect as another emitter within the same group, the new emitter will not start unless the difference in volume between the two is significant. For example: if two emitters are started within a group with the same sound effect and similar volume levels, MusyX will prevent the second one from starting until the difference between the volume levels of the emitters is beyond some hardcoded threshold.

The reason for this behavior is to preserve voice count. Also, this algorithm mitigates possible wave-cancellation effects caused by similar sound sources that are in very close proximity.

Note that a maximum of 32 emitters may be started in the same audio frame. The number of simultaneous emitters is otherwise limited only by the number of voices available to MusyX.
