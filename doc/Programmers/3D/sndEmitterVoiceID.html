sndEmitterVoiceID

SND_VOICEID sndEmitterVoiceID(SND_EMITTER *em);

Purpose:

This function gets the current voice ID of the SFX handled by the emitter specified.

Input:

SND_EMITTER *em
Pointer to a sturcture containing the current settings of the emitter.

Output:

If the SFX is active, the function will return its handle. If not, SND_ID_ERROR will be returned. Even the latter value may be passed to all SFX functions without any negative side effects.
