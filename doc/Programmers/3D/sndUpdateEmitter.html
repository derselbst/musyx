sndUpdateEmitter

bool sndUpdateEmitter(SND_EMITTER *em, SND_FVECTOR *pos, SND_FVECTOR *dir, u8 maxVol, SND_ROOM *room);

Purpose:

This function updates an emitter structure.

SND_EMITTER *em
Pointer to a sturcture containing the current settings of the emitter.

SND_FVECTOR *pos
Pointer to a vector containing the new position of the emitter.

SND_FVECTOR *dir
Pointer to a vector containing the new movement direction of the emitter.

u8 maxvol
Volume to be used at the postition of the listener for this emitter.

SND_ROOM *room
A pointer to a structure that describes a room's properties. Currently not supported, this value should be set to NULL.

Output:

Returns TRUE if successful, FALSE otherwise.
