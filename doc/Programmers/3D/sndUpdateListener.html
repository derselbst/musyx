sndUpdateListener

bool sndUpdateListener(SND_LISTENER *li, SND_FVECTOR *pos, SND_FVECTOR *dir, SND_FVECTOR *heading, SND_FVECTOR *up, u8 vol, SND_ROOM *room);

Purpose:

This function updates a listener structure.

Input:

SND_LISTENER *li
Pointer to a structure containing the current settings of the listener.

SND_FVECTOR *pos
Pointer to a vector containing the new position of the listener.

SND_FVECTOR *dir
Pointer to a vector containing the new movement direction of the listener.

SND_FVECTOR *heading
Pointer to a vector containing the newnormalized viewing direction of the listener.

SND_FVECTOR *up
Pointer to a vector containing the new normalized up vector of the listener.

u8 vol
Overall volume value to be applied to all emitters that are audible to this listener.

SND_ROOM *room
Pointer to a room description. For now, this pointer must be set to NULL.

Output:

Returns TRUE if successful, FALSE otherwise.
