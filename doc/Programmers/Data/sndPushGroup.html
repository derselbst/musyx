sndPushGroup

bool sndPushGroup(voice *prj_data, SND_GROUPID gid, void *samples, void *sampdir, void *pool);

Purpose:

This function pushes group data onto the soundstack. See Basic Architecture's Data Management for more details.

Input:

void *prj_data
Pinter to project data.

SND_GROUPID gid
ID of the group to be pushed.

void *samples
Pointer to sample data/ID to reference data.

void *sampdir
Pointer to sample directory containing data to locate samples within the sample data.

void *pool
Pointer to pool data.

Output:

Returns TRUE if successful, FALSE otherwise.
