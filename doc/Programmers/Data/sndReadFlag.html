sndReadFlag

s32 sndReadFlag(u8 num);

Purpose:

This function reads the flag value from the synthesizer. Flags may be used to signal certain conditions of the synthesizer to the main program. Flags are accessed as "global variables" from within a macro. There are 16 flags.

Input:

u8 num
Number of flag to read from.

Output:

Returns value obtained from flag. Default after startup is zero.
