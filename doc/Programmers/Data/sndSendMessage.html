sndSendMessage

bool sndSendMessage(SND_VOICEID vid, s32 mesg);

Purpose:

As its name implies, this function sends a message to a specified sound. The message consists of a 32-bit value. If the macro is designed to react to messages, this can be used to trigger certain changes in the sound.

Input:

SND_VOICEID vid
Voice ID of the sound to which the message should be sent.

s32 message
The "message" to be sent.

Output:

Returns TRUE if successful, FALSE otherwise. An example of a condition that would cause the call to fail would be if the voice ID is no longer active.
