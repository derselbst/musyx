sndSetSampleDataUploadCallback

void SNDCALL sndSetSampleDataUploadCallback(void *(*callback)(u32 offset, u32 bytes), u32 chunkSize);

Purpose:

Install a callback function that will be invoked by sndPushGroup() when sample data is needed for transfer into ARAM.

If a callback function is never registered by your application, then sndPushGroup() will require that the entire sample buffer for a given group be present in main memory before pushing that group onto the sound stack. However, this is often impractical because a sample set could be several megabytes in length.

By installing a callback, your application can minimize the amount of main memory buffer needed to transfer sample data from disk into ARAM. MusyX will use the callback to 'chunk' or 'stream' the contents of a sample file into ARAM through a user-defined buffer..

See sndPushGroup() and Basic Architecture's Data Management for more details.

Input:

void *(*callback)(u32 offset, u32 bytes)
Function that will be called when MusyX is ready to transfer a chunk of sample data into ARAM. The function will be invoked with the following arguments:

u32 offset
This is the current offset, in bytes, into the sample data file which is currently being transferred into ARAM.

u32 bytes
This is the number of bytes needed for the next chunk of data to be transferred into ARAM. Note that this value will not exceed the chunkSize parameter (see below).

The callback is responsible for reading data at the given offset and length from the appropriate *.sample file. The callback is also responsible for allocating memory for the buffer from which MusyX will transfer data into ARAM.

The callback must return a pointer (of type void) to the buffer containing the current 'chunk' of sample data. MusyX will then transfer that chunk into ARAM using the ARAM Queue (ARQ) driver.

If callback is NULL, sndPushGroup() will assume that the entire sample set is available in main memory and will transfer it all at once.

Note that the void *samples argument of sndPushGroup() must be set to NULL if you register a data upload callback.

u32 chunkSize
The number of bytes to DMA into ARAM per transfer. This value will be rounded up to the nearest multiple of 32. Note that this value must be equal to or greater than the chunk size used by ARQ. Please see the ARQGetChunkSize() and ARQSetChunkSize() functions in the Dolphin reference documentation.

Output:

None.
