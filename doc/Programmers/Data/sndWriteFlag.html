sndWriteFlag

s32 sndWriteFlag(u8 num, s32 value);

Purpose:

This function writes a flag value to the synthesizer. Flags may be used to signal certain conditions of the synthesizer to the main program. Flags are accessed as "global variables" from within the macro. There are 16 flags.

Input:

u8 num
Number of flag to which to write.

s32 value
Value to write to specified flag.

Output:

Returns the old value of the flag.
