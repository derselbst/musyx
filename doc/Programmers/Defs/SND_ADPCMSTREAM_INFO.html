SND_ADPCMSTREAM_INFO

typedef struct SND_ADPCMSTREAM_INFO {
				u8		initialPS;
				u8		reserved;
				u16		numCoef;
				s16		coefTab[8][2];
			} SND_ADPCMSTREAM_INFO;
The fields in this structure have to be initialized with values appropriate to the sample data to be streamed into this buffer. If these values change at some point, a new stream buffer needs to be allocated.

initialPS
This is the initial predictor/scale byte from the ADPCM data stream to be passed into this buffer. This is usually the first byte in the data. The system needs to know this value ahead of time, because of internal hardware requirements.

numCoef
This field contains the total number of coefficient pairs to be used to decode the sample material to be streamed. The maximum number supported is 8. The encoder will usually use all 8 pairs for maximum quality.

coefTab
This is the actual coefficient data from the ADPCM encoder tool in s16 format (as generated by the tool).

The info structure can be removed from memory after the callt o this function has been completed.
