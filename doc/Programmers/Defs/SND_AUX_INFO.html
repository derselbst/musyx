SND_AUX_INFO

typedef struct SND_AUX_INFO {
	union SND_AUX_DATA {
		struct SND_AUX_BUFFERUPDATE {
			s32	*left;
			s32	*right;
			s32	*surround;
			} bufferUpdate;
		struct SND_AUX_PARAMETERUPDATE {
			u16	para[SND_AUX_NUMPARAMETERS];
			} parameterUpdate;
		} data;
	} SND_AUX_INFO;

This structure contains data needed to properly react to the reason code passed by the function arguments in the sndSetAuxProcessingCallbacks(). Depending on the code either the fields in the SND_AUX_BUFFERUPDATE structure or in the SND_AUX_PARAMETERUPDATE are valid. Below find a list of all the fields.

s32 *left
Pointer to a buffer containing 5ms of 32KHz, 32 bit, signed PCM audio data for the left channel. The buffer serves as both input and output buffer for the algorithm.

s32 *right
Pointer to a buffer containing 5ms of 32KHz, 32 bit, signed PCM audio data for the right channel. The buffer serves as both input and output buffer for the algorithm.

s32 *surround
Pointer to a buffer containing 5ms of 32KHz, 32 bit, signed PCM audio data for the surround channel. The buffer serves as both input and output buffer for the algorithm.

u16 para[SND_AUX_NUMPARAMETERS]
New values for all parameters as reflected by newly received custom controller MIDI values.
