SND_STUDIO_INPUT

typedef struct SND_STUDIO_INPUT {
	u8	vol;
	u8	volA;
	u8	volB;
	u8	srcStudio;
	} SND_STUDIO_INPUT;

vol specifies the mixing volume when the source studio is mixed with the main bus of the destination studio.

volA specifies the mixing volume when the source studio is mixed with the AuxA bus of the destination studio.

volB specifies the mixing volume when the source studio is mixed with the AuxB bus of the destination studio.

srcStudio specifies the source studio.
