sndDbgGetActiveVoices

SNDEXPORT u8 SNDCALL sndDbgGetActiveVoices(void);

Purpose:

This function returns the maximum number of active voices used by MusyX in the previous audio frame. Note that audio frames occur every 5 msec.

Note also that this function only exists in the DEBUG library of MusyX. It is not available in the release version.

Input:

None.

Output:

An unsigned integer.
