sndInit

s32 sndInit (u8 voices, u8 music, u8 sfx, u8 studios, u32 flags, u32 aramsize);

Purpose:

This function initializes the sound system. It must be called once before any other routines of the system are used.

Note that the master volume (for both music and sound effects) will be zero after initialization is complete. The application must set the master volume level before sound will be audible. See sndVolume().

Input:

u8 voices
Specifies the maximum number of voices to be mixed at a time. The mazimum number of voices allowed on Dolphin is 64.

u8 music
Specifies the maximum number of voices that can be used by the synthesizer to playback instruments.

u8 sfx
Specifies the maximum number of voices that can be used by the synthesizer to playback sound effects.

u8 studios
Specifies the maximum number of studios that the application will use. MusyX will allocate approximately 15KB of main memory for each studio. MusyX supports a minimum of one studio and maximum of 8. A studio is a 'mixing context'. A set of voices may be mixed into a studio; the studio may then be added to other studios, or be passed through an Aux effect bus. Thus, studios are useful for modulating an arbitrary subset of voices. Note that most applications will only require one studio. Using multiple studios is an advanced technique that is relatively costly in terms of DSP processing cycles and memory usage.

u32 flags
These flags are used to trigger specific behaviors of the sound system. Most flags are platform specific and can be found in the Musician's Reference. A few, however, are platform independent.

SND_FLAGS_DEFAULT
Default settings are used.

SND_FLAGS_EMITTERGROUPSUSEMAXVOICES
This flag modifies the starting criteria for 3D emitters. Please see the "non-EX" sndAddEmitter functions for more details.

u32 aramSize
This specifies the maximum amount of ARAM that MusyX will use. Note that this is a contiguous block of memory, and always starts at the bottom of user-ARAM space (as indicated by the ARGetBaseAddress() function).

Output:

The function returns a value of 0, if successful.
