sndReinit

s32 sndReinit (u8 voices, u8 music, u8 sfx, u32 flags);

Purpose:

This function reinitializes the sound system. It must be called once after a temporary shutdown, before any other routines are used.
The system will initialize with no voices active and the main volume for music and FX down.

Input:

All input parameters are identical to the sndInit function.

u8 voices
Specifies the maximum number of voices to be mixed at a time. The mazimum number of voices allowed on Dolphin is 64.

u8 music
Specifies the maximum number of voices that can be used by the synthesizer to playback instruments.

u8 sfx
Specifies the maximum number of voices that can be used by the synthesizer to playback sound effects.

u32 flags
These flags are used to trigger specific behaviors of the sound system. Most flags are platform specific and can be found in the Musician's Refernce. A few, however, are platform independent.

SND_FLAGS_DEFAULT

Default settings are used.

Output:

None.
