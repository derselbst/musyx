sndSetHooks

void sndSetHooks(void * (*malloc) (u32 size), void (*free)(void *addr));

Purpose:

This function must be called even before sndInit(). Since the Dolphin OS has no predefined way to allocate memory, the user has to provide the basic functionality to MusyX. This function registers an allocation and a deallocation routine with MusyX.

Input:

void* (*malloc)(u32 size)
Pointer to a memory allocation function. The function has to return a pointer to a memory area not smaller than size bytes, which is aligned to a 32-byte boundary.

void (*free)(void *addr)
Pointer to a memory deallocation function. The function will always be called with a valid pointer previously returned by the above allocation function. In contrast to the ANSI free() function, this function does not need to implement any code to react to a NULL pointer.

Output:

None
