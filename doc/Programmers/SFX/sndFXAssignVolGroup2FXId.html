sndFXAssignVolGroup2FXId

bool sndFXAssignVolGroup2FXId(SND_FXID fid, u8 vgroup);

Purpose:

This function assigns a user-defined volume group to the specified sound effect ID. All sound effects using this ID started after this call will be controlled by the given volume group. If SND_FX_VOLGROUPS is passed, the FX ID is passed back to the default SFX volume group.

Input:

SND_FXID fid
FX to which the volume group should be assigned.

u8 vgroup
Volume group to be assigned.

Output:

Returns TRUE if successful, FALSE if not.
