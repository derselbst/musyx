sndFXCtrl14

bool sndFXCtrl(SND_VOICEID vid, u8 ctrl, u16 value);

Purpose:

This function sets a new 14-bit controller value.

Input:

SND_VOICEID vid
The voice ID obtained through sndFXStart() or sndFXStartEX().

u8 ctrl
The controller to be influenced.

u8 value
The new value to be set.

Output:

Returns TRUE if successful, FALSE otherwise.
