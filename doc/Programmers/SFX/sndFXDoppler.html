sndFXDoppler

bool sndFXDoppler(SND_VOICEID vid, u16 doppler);

Purpose:

This function sets a new Doppler value for the specified sound effect. The default Doppler value set after start is 0x2000. (0x2000=No pitch offset, lower values pitch down, higer values pitch up). In contrast to the pitch bend, the Doppler effect is applied by scaling the frequency, rather than offsetting the pitch by offsetting the current key.

Input:

SND_VOICEID vid
The voice ID obtained through sndFXStart() or sndFXStartEX().

u16 doppler
The new Doppler value to be applied to the effect.

Output:

Returns TRUE if successful, FALSE otherwise.
