sndFXModulation

bool sndFXModulation(SND_VOICEID vid, u16 modu);

Purpose:

This function sets a new modulation value for the specified sound effect. The default modulation value after start is 0. (0=Lowest, 16383=Highest).

Input:

SND_VOICEID vid
The voice ID obtained through sndFXStart() or sndFXStartEX().

u16 modu
The new modulation value to be applied to the effect.

Output:

Returns TRUE if successful, FALSE otherwise.
