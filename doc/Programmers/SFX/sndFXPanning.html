sndFXPanning

bool sndFXPanning(SND_VOICEID vid, u8 pan);

Purpose:

This function sets a new panning offset for the specified sound effect. The default panning offset after start is 64. (0=Left, 64=Center, 127=Right, 128= Surround (surround is a legacy feature, do not use)).

Input:

SND_VOICEID vid
The voice ID obtained through sndFXStart() or sndFXStartEX().

u8 pan
The new panning value to be applied to the effect.

Output:

Returns TRUE if successful, FALSE otherwise.
