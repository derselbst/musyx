sndFXPedal

bool sndFXPedal(SND_VOICEID vid, u8 pedal);

Purpose:

This function sets a new pedal state for the specified sound effect.

Input:

SND_VOICEID vid
The voice ID obtained through sndFXStart() or sndFXStartEX().

u8 pedal
The new pedal state. If the pedal controller is still mapped to the pedal input of the synthesizer (see Musician's Reference Guide) a value lower than 0x3F will clear the pedal state, while a larger value will set it.

Output:

Returns TRUE if successful, FALSE otherwise.
