sndFXPitchBend

bool sndFXPitchBend(SND_VOICEID vid, u16 pb);

Purpose:

This function sets a new pitch bend value for the specified sound effect. The default pitch bend value set after start is 0x2000. (0x2000=No pitch offset, lower values=pitch down, higher values=pitch up).

Input:

SND_VOICEID vid
The voice ID obtained through sndFXStart or sndFXStartEX.

u16 pb
The new pitch bend value to be applied to the effect.

Output:

If the SFX is active, the function will return its handle. If not, SND_ID_ERROR will be returned. Even the latter value may be passed to all SFX functions without any negative side effects.
