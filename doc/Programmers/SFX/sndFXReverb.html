sndFXReverb

bool sndFXReverb(SND_VOICEID vid, u8 rvol);

Purpose:

This function sets a new reverb volume for the specified sound effect.

Input:

SND_VOICEID vid
The voice ID obtained through sndFXStart() or sndFXStartEX().

u8 rvol
The new reverb volume to be set.

Output:

Returns TRUE if successful, FALSE otherwise.
