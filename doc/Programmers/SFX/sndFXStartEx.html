sndFXStartEx

SND_VOICEID sndFXStartEx(SND_FXID fid, u8 vol, u8 pan, u8 studio);

Purpose:

This function starts a sound effect.

Input:

SND_FXID
Specifies the ID of the sound effect to be used.

u8 vol
Specifies the default volume to be used with this sound effect. This value may or may not be used by the sound effect. (0=Silence, 127=100%, 0xFF=Use default volume).

u8 pan
Specifies the default panning to be used with this sound effect. This value may or may not be used by the sound effect. (0=Left, 64=Center, 127=Right, 128=Surround (this is a legacy feature - do not use), 0xFF=Use default panning).

u8 studio
Specifies the studio to be used to play the sound effect.

Output:

Returns SND_ID_ERROR if failed, a voice ID if successful.
