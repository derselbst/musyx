sndFXStartParaInfo

SND_VOICEID sndFXStartParaInfo(SND_FXID fid, u8 vol, u8 pan, u8 studio, SND_PARAMETER_INFO *paraInfo);

Purpose:

This function starts a sound effect and immediately sets some MIDI controller values. This call encapsulates a simple sound effect start and the setting of a number of MIDI controllers in one call. This not only simplifies the process, it avoids audible artifacts caused by the sound system and callback being issued before all MIDI controller values are set. Using multiple funciton calls can cause this problem.

Input:

SND_FXID
Specifies the ID of the sound effect to be used.

u8 vol
Specifies the default volume to be used with this sound effect. This value may or may not be used by the sound effect. (0=Silence, 127=100%, 0xFF=Use default volume).

u8 pan
Specifies the default panning to be used with this sound effect. This value may or may not be used by the sound effect. (0=Left, 64=Center, 127=Right, 128=Surround (this is a legacy feature - do not use), 0xFF=Use default panning).

u8 studio
Specifies the studio to be used to play the sound effect.

SND_PARAMETER_INFO
Structure defining additional MIDI controller values to be set after the FX has been started.

Output:

Returns SND_ID_ERROR if unsuccessful, a voice ID otherwise.
