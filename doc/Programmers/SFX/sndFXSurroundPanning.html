sndFXSurroundPanning

bool sndFXSurroundPanning(SND_VOICEID vid, u8 pan);

Purpose:

This function sets a new surround panning offset for the specified sound effect. The default panning offset after start is 0. (0=Front, 64=Center, 127=Back).

Input:

SND_VOICEID vid
The voice ID obtained through sndFXStart() or sndFXStartEX().

u8 pan
The new surround panning value to be applied to the effect.

Output:

Returns TRUE if successful, FALSE otherwise.
