sndFXVolume

bool sndFXVolume(SND_VOICEID vid, u8 vol);

Purpose:

This function sets a new volume for the specified sound effect. The default volume after start is 127. (0=Silence, 127=100%).

Input:

SND_VOICEID vid
The voice ID obtained through sndFXStart() or sndFXStartEX().

u8 vol
The new volume value to be applied to the effect.

Output:

Returns TRUE if successful, FALSE otherwise.
