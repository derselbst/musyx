sndSeqCrossfade

void sndSeqCrossfade(SND_CROSS_FADE *ci, SND_SEQID *new_seq_id);

Purpose:

This function initiates a cross fade between two pieces of music.

Input:

SND_CROSSFADE *ci
Pointer to a structure containing all necessary information to perform the cross fade.

SND_SEQID *new_seq_id
Pointer to a ULONG that will be assigned the new sequencer ID as soon as it is available. A temporary ID will be assigned immediately, while the real ID will be assigned at some point during the cross fade. This variable must be present during the cross fade for that reason. The temporary ID can be used for most control purposes, as long as no real ID is generated.

Output:

None.
