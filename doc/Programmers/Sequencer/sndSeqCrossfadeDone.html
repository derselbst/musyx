sndSeqCrossfadeDone

bool sndSeqCrossfadeDone(SND_SEQID *new_seqId);

Purpose:

This function checks to see if a cross fade has finished.

Input:

SND_SEQID
ID that specifies which sequencer is to be checked. The ID specified is that of the new song, not the old one.

Output:

The function returns TRUE if the cross fade is complete, otherwise FALSE is returned.
