sndSeqGetMidiCtrl

u8 sndSeqGetMidiCtrl(SND_SEQID sequid, u8 channel, u8 ctrl);

Purpose:

This function returns the current value of the specified MIDI controller for the given sequencer instance.

Input:

SND_SEQUID sequid
ID of song/sequencer about which the function reports.

u8 channel
MIDI channel for which to request data.

u8 ctrl
MIDI controller number (0-127).

Output:

Returns the current controller value.
