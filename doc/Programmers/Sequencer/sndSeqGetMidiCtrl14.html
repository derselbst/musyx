sndSeqGetMidiCtrl14

u16 sndSeqGetMidiCtrl14(SND_SEQID seqId, u8 channel, u8 ctrl);

Purpose:

This function returns the current value of the specified MIDI controller for the given sequencer instance. To support easy access to "high-res" controllers, this function returns a 14-bit controller value. For standard 7-bit "low-res" controller values, the value is shifted 7 bits to the left (0x40 becomes 0x2000). MusyX extended controller numbers are supported.

Input:

SND_SEQID
ID of song/sequencer to affect.

u8 channel
MIDI channel for which data is requested.

u8 ctrl
MIDI controller number (0-127).

Output:

Returns the current 14-bit controller value.
