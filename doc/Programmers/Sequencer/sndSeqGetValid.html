sndSeqGetValid

bool sndSeqGetValid(SND_SEQID sequid);

Purpose:

This function is used to determine if the song is actually playing or still in a temporary state. Songs may be in a temporary state immediatley after or during cross fades.

Input:

SND_SEQID
ID of the song/sequencer.

Output:

Returns TRUE if the sequencer is playing the song specified by the ID. FALSE is returned if the ID is temporary.
