sndSeqGetVolGroup

u8 sndSeqGetVolGroup(SND_SEQID sequid);

Purpose:

This function returns the volume group index that has been assigned to the given song/sequencer.

Note that users can assign single tracks within a given sequencer instance to particular volume groups; these are not returned by this function. This function only returns the overall volume group index assigned to the sequencer.

Input:

SND_SEQUID sequid
ID of song/sequencer to be queried.

Output:

The volume group used to control the default song/sequencer volume.
