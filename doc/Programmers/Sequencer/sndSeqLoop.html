sndSeqLoop

bool sndSeqLoop(SND_SEQID sequid, bool on);

Purpose:

This function allows the looping of songs to be disabled. By default, looping is enabled, if the musician defined loop locators. Disabling looping may be useful if, for example, a song is meant to loop a couple of times before it ends.

Input:

SND_SEQID
ID of the affected sequencer.

bool on
A value of TRUE will enable looping (default), FALSE disables.

Output:

The function will return TRUE if successful, FALSE otherwise.
