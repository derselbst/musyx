sndSeqMute

void sndSeqMute(SND_SEQID sequid, u32 mask1, u32 mask2);

Purpose:

This function mutes/demutes single tracks from the sequencer file. The 64 tracks are represented by 2 u32s.

Input:

SND_SEQID
ID that specifies which sequencer is to be affected.

mask1
Mute mask for the lower 32 tracks. A 0 mutes the corresopnding channel.

mask2
Mute mask for the upper 32 tracks. A 0 mutes the corresopnding channel.

Output:

None.
