sndSeqPlay

SND_SEQID sndSeqPlay (SND_GROUPID sgid, SND_SONGID sid, void *arrfile, SND_PLAYPARA *para);

Purpose:

This function starts the playback of a song contained within a song group.

Input:

SND_GROUPID sgid
Specifies the ID of the song group to be used as a source.

SND_SONGID sid
Specifies which sequencer file in the song group is to be used.

void *arrfile
Pointer to memory contianing sequencer data. Certain alignment requirements may apply for certain platforms.

SND_PLAYPARA *para
Pointer to a structure containing various parameters for starting the song. If this pointer is set to NULL, the song will be started immediately, and no volume will be set. By default, the volume is down.

Output:

The function returns a 32-bit sequencer ID if successful, if not it returns SND_SEQ_ERROR_ID.
