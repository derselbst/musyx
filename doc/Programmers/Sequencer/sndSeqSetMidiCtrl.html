sndSeqSetMidiCtrl

bool sndSeqGetMidiCtrl14(SND_SEQID seqId, u8 channel, u8 ctrl, u8 value);

Purpose:

This function sets a new 7-bit value to the specified MIDI controller for the given sequencer instance.

Input:

SND_SEQID
ID of song/sequencer about which information is reported.

u8 channel
MIDI channel for which data is requested.

u8 ctrl
MIDI controller number (0-127).

u8 value
New value to be set.

Output:

Returns TRUE if successful, FALSE otherwise.
