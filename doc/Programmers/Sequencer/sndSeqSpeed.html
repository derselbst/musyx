sndSeqSpeed

void sndSeqSpeed(SND_SEQID sequid, u16 speed);

Purpose:

This function changes the playback speed of the specified sequencer.

Input:

SND_SEQID
ID of the affected sequencer.

u16 speed
Speed to be set. A value of 0x100 will reset the speed to normal. Lower values will slow down playback, higher values will speed it up.

Output:

None.
