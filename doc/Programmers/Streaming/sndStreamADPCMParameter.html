sndStreamADPCMParameter

void sndStreamADPCMPParameter(SND_STREAMID stid, SND_ADPCMSTREAM_INFO *adpcmInfo);

Purpose:

This function changes the ADPCM parameters for a given stream.. The new parameters will take effect on the next (5msec) audio frame.

This function may be invoked from within the update callback for a given (ADPCM) stream. The application must ensure that the given stream is 'quiescent'. In other words, the application must ensure that the stream is silent before changing the ADPCM parameters and providing new data.

Input:

u32 stid
Handle of stream to be manipulated. The stream must be MONO.

SND_ADPCMSTREAM_INFO *adpcmInfo
Pointer to a structure containing the ADPCM coefficients needed to playback the ADPCM stream.. The structure has the following format:

  typedef struct SND_ADPCMSTREAM_INFO
  {
      s16 coefTab[8][2]; // Table of coef. pairs

  } SND_ADPCMSTREAM_INFO;

Note that the NINTENDO GAMECUBE SDK contains a command-line tool (DSPADPCM.EXE) for converting WAV or AIFF data into DSP-ADPCM format. This tool will generate the coefficients needed to initialize the adpcmInfo structure.

Output:

None.
