sndStreamARAMUpdate

void sndStreamARAMUpdate(SND_STREAMID stid, u32 off1, u32 len1, u32 off2, u32 len2);

Purpose:

This function manually updates ARAM copy of MRAM stream buffer.

This function is intended for use with software streams which have been allocated with the SND_STREAM_MANUALARAMUPD flag.

This function does NOT support stereo streams.

Input:

u32 stid
Handle of stream to be affected.

u32 off1
Offset of the first buffer area to transfer.

u32 len1
Length of the first buffer area to transfer.

u32 off2
Offset of the second buffer area to transfer.

u32 len2
Length of the second buffer area to transfer.

Output:

None.
