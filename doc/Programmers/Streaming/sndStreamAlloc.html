sndStreamAlloc

u32 sndStreamAlloc(u8 prio, void *buffer, u32 size, u32 frq, u8 vol, u8 pan, u8 span, u8 fxvol, u32 (*update_function) (void *buffer1, u32 len1, void *buffer2, u32 len2, u32 user), u32 user);

Purpose:

This function allocates a stream buffer in ARAM. The function will immediately activate the buffer for streaming by allocating a voice. The update function specified will be called in approximately 20ms intervals.

Input:

u8 prio Priority to be used for allocating the voice to be used for playing the stream. To guarantee allocation, the priority should be chosen as high as possible (255).

void *buffer
Pointer to buffer in MRAM allocated by the application. The neccesary size can be inquired by calling sndStreamAllocLength().

u32 size
Size of the ring buffer in samples.

u32 frq
Frequency in Hz to be used for playback.

u8 vol
Volume used for playback (0-127).

u8 pan
Panning used for playback (0-127).

u8 span
Surround panning used for playback (0-127).

u8 fxvol
Reverb (AuxA) volume used for playback (0-127).

u8 (*update_function)(void *buffer1, u32 len1, void *buffer2, u32 len2, u32 user)
Pointer to a function that will be called by MusyX each time that the buffer has to be updated. Buffer1 and len1 define the first area to be updated, while buffer2 and len2 define the second area. Two areas are necessary, since the buffer is a ring buffer, and the area to be updated may wrap around. Len2 will be zero if no second area is needed. User is a value specified by the application.

u32 user
User-defined value to be passed to the update function. For example, it can be used to identify different instances of streams to the update function.

Output:

The function returns a handle to the stream if successful and SND_ID_ERROR if not.
