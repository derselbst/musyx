sndStreamAllocEx

SND_STREAMID sndStreamAllocEx(u8 prio, void *buffer, u32 samples, u32 frq, u8 vol, u8 pan, u8 span, u8 auxa, u8 auxb, u8 studio, u32 flags, u32 (*updateFunction)(void *buffer1, u32 len1, void *buffer2, u32 len2, u32 user), u32 user, SND_ADPCMSTREAM_INFO *adpcmInfo);

Purpose:

This function allocates a stream buffer in ARAM. By default the function will immediately activate the buffer for streaming by allocating a voice. The update function will be called in approximately 20ms intervals.

Input:

u8 prio Priority to be used for allocating the voice to be used for playing the stream. To guarantee allocation, the priority should be chosen as high as possible (255).

void *buffer
Pointer to buffer in MRAM allocated by the application. The neccesary size can be retrieved by calling sndStreamAllocLength().

u32 samples
Length of the ring buffer in samples.

u32 frq
Stream frequency in Hz.

u8 vol
Volume used for playback (0-127).

u8 pan
Stereo panning used for playback (0-127).

u8 span
Surround panning used for playback (0-127).

u8 auxa
AuxA volume.

u8 auxb
Auxb volume.

u8 studio
Studio in which the stream should be played.

u32 flags
Any combination (unless noted otherwise) of the following flags are allowed:

SND_STREAM_DEFAULT
Allocate and activate PCM16 stream.

SND_STREAM_ADPCM
The stream is in ADPCM format.

SND_STREAM_INACTIVE
A buffer in ARAM will be allocated, but no voice will be allocated yet. A subsequent call to sndStreamActivate() can be used to activate playback. This can prevent fragmentation of ARAM memory.

SND_STREAM_MANUALARAMUPD
By default, MusyX will transfer stream data provided by the application from MRAM into ARAM during the update callback. This flag will disable this behavior so that the application may use some other event to trigger the ARAM transfer. The application must use sndStreamARAMUpdate() to manually transfer data from MRAM into ARAM.

u8 (*update_function)(void *buffer1, u32 len1, void *buffer2, u32 len2, u32 user)
Pointer to a function that will be called by MusyX each time that the buffer has to be updated. Buffer1 and len1 define the first area to be updated, while buffer2 and len2 define the second area. Two areas are necessary, since the buffer is used as a ring buffer, and the area to be updated may wrap around. Len2 will be zero if no second area is needed. User is a value specified by the application.

u32 user
User-defined value to be passed to the update function.

SND_STREAMADPCM_INFO *adpcmInfo
Pointer to a structure containing the ADPCM coefficients needed to play the ADPCM stream. If the stream is PCM16 format or not immediately activated, this pointer may be NULL. The structure has the following format:

  typedef struct SND_ADPCMSTREAM_INFO
  {
      s16 coefTab[8][2]; // Table of coef. pairs

  } SND_ADPCMSTREAM_INFO;

Note that the NINTENDO GAMECUBE SDK contains a command-line tool (DSPADPCM.EXE) for converting WAV or AIFF data into DSP-ADPCM format. This tool will generate the coefficient data needed for the adpcmInfo structure.

Output:

The function returns a handle to the stream if successful and SND_ID_ERROR if not.
