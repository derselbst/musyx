sndStreamAllocLength

u32 sndStreamAllocLength(u32 num, u32 flags);

Purpose:

This function returns the number of bytes needed in MRAM   for a stream buffer, containing the specifed number of samples.

Input:

u32 num Number of samples in the buffer.

u32 flags Flag determines the type of stream data.

SND_STREAM_DEFAULT
This flag will cause the system to allocate a PCM16 stream buffer.

SND_STREAM_ADPCM
this flag will allocate an ADPCM stream buffer.

Output:

Size of the buffer that has to be allocated in bytes
