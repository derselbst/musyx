sndStreamAllocStereo

SND_STREAMID sndStreamAllocStereo(u8 prio, void *lBuffer, void *rBuffer, u32 samples, u32 frq, u8 vol, u8 pan, u8 span, u8 auxa, u8 auxb, u8 studio, u32 flags, u32 (*updateFunction)(void *buffer1, u32 len1, void *buffer2, u32 len2, u32 user), u32 lUser, u32 rUser, SND_ADPCMSTREAM_INFO *adpcmInfoL, SND_ADPCMSTREAM_INFO *adpcmInfoR);

Purpose:

This function allocates a stereo stream buffer pair in ARAM. By default the function will immediately activate the buffers for streaming by allocating two voices. The update function will be called in approximately 20ms intervals.

Note that stereo streams do not currently support manual ARAM updates. Furthermore, the ADPCM parameters for stereo streams cannot currently be updated after allocation.

Input:

u8 prio Priority to be used for allocating the voice to be used for playing the stream. To guarantee allocation, the priority should be chosen as high as possible (255).

void *lBuffer, *rBuffer
Pointers to the left-channel and right-channel MRAM buffers allocated by the application. The neccesary size can be retrieved by calling sndStreamAllocLength().

u32 samples
Length of the ring buffer in samples.

u32 frq
Stream frequency in Hz.

u8 vol
Volume used for playback (0-127).

u8 pan
Stereo panning used for playback (0-127).

u8 span
Surround panning used for playback (0-127).

u8 auxa
AuxA volume.

u8 auxb
AuxB volume.

u8 studio
Studio in which the stream should be played. User 'zero' for default.

u32 flags
Any combination (unless noted otherwise) of the following flags are allowed:

SND_STREAM_DEFAULT
Allocate and activate PCM16 stream.

SND_STREAM_ADPCM
The stream is in ADPCM format.

SND_STREAM_INACTIVE
A buffer in ARAM will be allocated, but no voice will be allocated yet. A subsequent call to sndStreamActivate() can be used to activate playback. This flag is useful for allocating a stream buffer in ARAM, then reusing it throughout the lifetime of an application. Such a strategy mitigates the possibility of fragmenting ARAM by continually allocating and freeing software streams during runtime.

u8 (*update_function)(void *buffer1, u32 len1, void *buffer2, u32 len2, u32 user)
Pointer to a function that will be called by MusyX each time that the buffer has to be updated. Buffer1 and len1 define the first area to be updated, while buffer2 and len2 define the second area. Two areas are necessary, since the buffer is used as a ring buffer, and the area to be updated may wrap around. Len2 will be zero if no second area is needed. User is a value specified by the application.

u32 lUser, rUser
User-defined values to be passed to the update function for left-channel and right-channel updates.

adpcmInfoL, adpcmInfoR
Pointers to structures containing the ADPCM coefficients needed to play the left-channel and right-channel ADPCM streams. If the streams arePCM16 format or not immediately activated, these pointers may be NULL.

Output:

The function returns a handle to the stream if successful and SND_ID_ERROR if not.
