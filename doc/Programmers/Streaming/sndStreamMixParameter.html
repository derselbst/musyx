sndStreamMixParameter

void sndStreamMixParameter(u32 stid, u8 vol, u8 pan, u8 span, u8 fxvol);

Purpose:

This function changes stream parameters during playback. The new parameters will take effect on the next (5msec) audio frame.

Input:

u32 stid
Handle of stream to be manipulated. If the handle points to a stereo pair, then both streams will be automatically updated.

u8 vol
New volume to be set.

u8 pan
New stereo panning to be set.

u8 span
New surround panning to be set.

u8 fxvol
New Aux A volume to be set.

Output:

None.
