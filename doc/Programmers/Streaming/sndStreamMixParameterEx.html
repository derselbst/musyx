sndStreamMixParameterEx

void sndStreamMixParameterEx(SND_STREAMID stid, u8 vol, u8 pan, u8 span, u8 auxa, u8 auxb);

Purpose:

This function changes stream playback parameters during playback.

Input:

u32 stid
Handle of stream to be manipulated. If the handle points to a stereo pair, then both streams will be automatically updated.

u8 vol
New volume to be set.

u8 pan
New panning to be set.

u8 span
New surround panning to be set.

u8 auxa
New AuxA volume to be set (reverb).

u8 auxb
New AuxB volume to be set (chorus).

Output:

None.
