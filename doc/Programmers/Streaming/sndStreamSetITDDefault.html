sndStreamSetITDDefault

void sndSetITDDefault(u8 studio, bool musicITD, bool sfxITD);

Purpose:

This function sets the default ITD state of sound effects and music voices for the specified studio. A studio by default has both these values set to FALSE. Note that a macro can always overwrite these default settings.

Input:

u8 studio
Handle of the studio.

musicITD
If TRUE, ITD is enabled for all music voices.

sfxITD
If TRUE, ITD is enabled for all sfx voices.

Output:

None.
