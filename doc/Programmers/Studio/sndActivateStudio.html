sndActivateStudio

void sndActivateStudio(u8 studio, bool isMaster);

Purpose:

This function creates a new studio.

Input:

u8 studio
This is a user-defined value between 1 and 8. This value specifies a unique studio. Note that zero is used for the default studio, SND_DEFAULT_STUDIO. The default studio cannot be activated or deactivated.

bool isMaster
TRUE or FALSE

TRUE
If TRUE, then the main bus of this studio will be added to the main bus of the default studio, after AUX processing of the default studio has occured. Thus, the AUX effects of the default studio will not be applied to the output of this studio.

FALSE
If FALSE, then the destination of this studio must be specified by the sndAddStudioInput() function.

Output:

None.
