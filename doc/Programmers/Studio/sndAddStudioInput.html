sndAddStudioInput

bool sndAddStudioInput(u8 studio, SND_STUDIO_INPUT *in_desc);

Purpose:

This function specifies the destination studio to which the source must be added.

The destination studio is specified by the u8 studio parameter. The source studio is specified in the SND_STUDIO_INPUT *in_desc structure.

The source studio is processed with its own set of AUX effects (as specified by sndSetAuxProcessingCallbacks()). The contents of the source studio's main bus are then distributed to the main, AuxA, and AuxB busses of the destination studio.

When the destination studio is processed, the contents of the source studio will 'inherit' the Aux effects asociated with the destination studio.

The source studio must have been previously activated using the sndActivateStudio() function. The master mix attribute of the source studio must be set to FALSE.

Input:

u8 studio
This is a user-defined value between 1 and 8. This value specifies a unique, previously activated destination studio.

SND_STUDIO_INPUT *in_desc
Pointer to a structure which describes how a studio should be added to the specified destination studio.

Output:

The function returns TRUE if it successfully directed the output of the source studio into the destination studio. The function returns FALSE if it failed.

Related:

sndSetAuxProcessingCallbacks.
