bool sndAddStudioInput(u8 studio, SND_STUDIO_INPUT *in_desc);

Purpose:

This function removes a source studio from the specified destination studio.

Input:

u8 studio
This is a user-defined value between 1 and 8. This value specifies a unique, previously activated destination studio.

SND_STUDIO_INPUT *in_desc
Pointer to a structure which describes a source, or input, studio..

Output:

The function returns TRUE if successful, FALSE if it failed.
