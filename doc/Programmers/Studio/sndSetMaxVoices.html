sndSetMaxVoices

s32 sndSetMaxVoices(u8 music,u8 sfx);

Purpose:

This function allows reinitializing the number of music or sound effects voices allowed at any time. It does not reinitialize the total number of voices, though. Also keep in mind, that no currently running voices are affected. Only newly allocated voices will use the new values.

Input:

u8 music
Number of music voices allowed.

u8 sfx
Number of sound effect voices allowed.

Output:

None.
