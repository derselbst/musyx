sndOutputMode

void sndOutputMode(SND_OUTPUTMODE mode)

Purpose:

This function sets the system to mono, stereo, or surround.

Input:

SND_OUTPUTMODE mode
Selects the output mode. The default mode is stereo.

SND_OUTPUTMODE_MONO: All sounds are panned equally between left and right channels.

SND_OUTPUTMODE_STEREO: Provides stereo output for all sounds panned to left, right, or surround channels.

SND_OUTPUTMODE_SURROUND: Provides surround-encoding for sounds that are panned to the surround channel.

Please note that switching between modes may cause a small pop or click artifact.

Output:

None.
