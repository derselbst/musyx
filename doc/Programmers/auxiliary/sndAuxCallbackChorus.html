sndAuxCallbackChorus

void sndAuxCallbackChorus(u8 reason, SND_AUX_INFO *info, void *user);

Purpose:

This callback function is to be used together with sndSetAuxProcessingCallbacks(). It implements a chorus effect.

Input:

u8 reason
Specifies the reason why the callback was invoked. The following codes are defined:

SND_AUX_REASON_BUFFERUPDATE
Buffers are ready for processing. Buffer pointers are specified in the info structure.

SND_AUX_REASON_PARAMETERUPDATE
MIDI parameters have been changed. Parameters are stored in the info structure.

SND_AUX_INFO *info
Pointer to an info structure containing data needed to properly react to the reason code passed by the caller. Depending on the code either the fields in the SND_AUX_BUFFERUPDATE structure or in the SND_AUX_PARAMETERUPDATE are valid.

void *user
This pointer must point to a structure of type SND_AUX_CHORUS prepared by sndAuxCallbackPrepareChorus().

Output:

None.
