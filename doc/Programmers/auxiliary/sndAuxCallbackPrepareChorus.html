sndAuxCallbackPrepareChorus

bool sndAuxCallbackPrepareChorus(SND_AUX_CHORUS *ch);

Purpose:

This function is used to initialize all fields not easily filled in by the application in the SND_AUX_CHORUS structure. it also will allocate buffer memory as necessary using the standard MusyX allocation callbacks.

Input:

SND_AUX_CHORUS *ch
Pointer to a SND_AUX_CHORUS structure partly initialized by the application.

Output:

Returns TRUE if successful, FALSE otherwise.
