sndAuxCallbackPrepareReverb

bool sndAuxCallbackPrepareReverb(SND_AUX_REBERB *rev);

Purpose:

This function is used to initialize all fields not easily filled in by the application in the SND_AUX_REVERB structure. It also will allocate buffer memory as necessary using the standard MusyX allocation callbacks.

Input:

SND_AUX_REVERB *rev
Pointer to a SND_AUX_REVERB structure partly initialized by the application.

Output:

The funciton returns TRUE if successful, FALSE if otherwise.
