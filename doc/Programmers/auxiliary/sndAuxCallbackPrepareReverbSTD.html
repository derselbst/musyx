sndAuxCallbackPrepareReverbSTD

bool sndAuxCallbackPrepareReverbSTD(SND_AUX_REVERBSTD *rev);

Purpose:

This function is used to initialize all fields not easily filled in by the application in the SND_AUX_REVERBSTD structure. It also will allocate buffer memory as necessary using the standard MusyX allocation callbacks.

Input:

SND_AUX_REVERBSTD *rev
Pointer to a SND_AUX_REVERBSTD structure partly initialized by the application.

Output:

Returns TRUE if successful, FALSE otherwise.
