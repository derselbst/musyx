sndAuxCallbackReverb

void sndAuxCallbackReverb(s32 *left, s32 *right, s32 *surround, void *user);

Purpose:

This callback function is used with sndSetAuxProcessingCallbacks. It implements a reverb algorithm.

Input:

s32 *left
Pointer to a buffer containing 5ms of 32-bit signed PCM audio data for the left channel. The buffer functions as both input and output buffer for the algorithm.

s32 *right
Pointer to a buffer containing 5ms of 32-bit signed PCM adio data for the right channel. The buffer functions as both input and output buffer for the algorithm.

s32 *surround
Pointer to a buffer containing 5ms of 32-bit signed PCM adio data for the surround channel. The buffer functions as both input and output buffer for the algorithm.

void *user
This pointer must point to a structure of type SND_AUX_REVERB prepared by sndAuxCallbackPrepareReverb.

Output:

None.
