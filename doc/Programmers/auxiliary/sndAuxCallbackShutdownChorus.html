sndAuxCallbackShutdownChorus

bool sndAuxCallbackShutdownChorus(SND_AUX_CHORUS *ch);

Purpose:

This function is used to free all resources originally allocated to run the effect.

Input:

SND_AUX_CHORUS *ch
Pointer to a SND_AUX_CHORUS structure of an initialized, but no longer active effect.

Output:

Returns TRUE if successful, FALSE otherwise.
