sndAuxCallbackShutdownDelay

bool sndAuxCallbackShutdownDelay(SND_AUX_DELAY *delay);

Purpose:

This function is used to free all resources originally allocated to run the effect.

Input:

SND_AUX_DELAY *delay
Pointer to a SND_AUX_DELAY structure of an initialized, but no longer active effect.

Output:

Returns TRUE if successful, FALSE otherwise.
