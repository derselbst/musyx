sndAuxCallbackShutdownReverbHI

bool sndAuxCallbackShutdownReverbHI(SND_AUX_REVERBHI *rev);

Purpose:

This function is used to free all resources originally allocated to run the effect.

Input:

SND_AUX_REVERBHI *rev
Pointer to a SND_AUX_REVERBHI structure of an initialized, but no longer active effect.

Output:

Returns TRUE if successful, FALSE otherwise.
