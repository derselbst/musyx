sndAuxCallbackShutdownReverbSTD

bool sndAuxCallbackShutdownReverbSTD(SND_AUX_REVERBSTD *rev);

Purpose:

This function is used to free all resources originally allocated to run the effect.

Input:

SND_AUX_REVERBSTD *rev
Pointer to a SND_AUX_REVERBSTD structure of an initialized, but no longer active effect.

Output:

Returns TRUE if successful, FALSE otherwise.
