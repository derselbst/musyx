sndAuxCallbackUpdateSettingsDelay

bool sndAuxCallbackUpdateSettingsDelay(SND_AUX_DELAY *delay);

Purpose:

This function is used to update the effect's parameters. Audible artifacts may occur while switching to the new setup.

Input:

SND_AUX_DELAY *delay
Pointer to a SND_AUX_DELAY structure which is currently used, but now features new user parameter settings.

Output:

Returns TRUE if successful, FALSE otherwise.
