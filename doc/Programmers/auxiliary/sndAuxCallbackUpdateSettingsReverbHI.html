sndAuxCallbackUpdateSettingsReverbHI

bool sndAuxCallbackUpdateSettingsReverbHI(SND_AUX_REVERBHI *rev);

Purpose:

This function is used to update the effect's parameters. Audible artifacts may occur while switching to the new setup.

Input:

SND_AUX_REVERBHI *rev
Pointer to a SND_AUX_REVERBHI structure which is currently used, but now features new user parameter settings.

Output:

Returns TRUE if successful, FALSE otherwise.
