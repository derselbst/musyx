sndSetAuxProcessingCallbacks

void sndSetAuxProcessingCallbacks(u8 studio, void (*auxA)(u8 reason, SND_AUX_INFO *info, void *user), void *userA, u8 midiA, SND_SEQID seqIDA, void (*auxB)(u8 reason, SND_AUX_INFO *info, void *user), void *userB, u8 midiB, SND_SEQID seqIDB);

Purpose:

MusyX allows registering users effects handling to be registered with each studio context. All data passed through the Aux A and/or Aux B busses of the specified studio will be passed through whatever effect engine is implemented by the user defined callback functions specified. The effect in question may be a special type of reverb, distortion, or anything else that can be done to digital audio signals. The funcitons have to handle 3 channels (left, right, surround) of signed 32-bit audio (24-bits used) at 32KHz, 5ms data at a time.

Input:

u8 studio
Studio for which aux bus callbacks should be modified.

void (*auxA)(u8 reason, SND_AUX_INFO *info, void *user)
Pointer to a function to be called when 5ms worth of data has to be processed for AUX A. NULL deactivates the callback.

The callback function's parameters are as follows:

u8 reason
Specifies the reason why the callback was invoked. The following codes are defined:

SND_AUX_REASON_BUFFERUPDATE
Buffers are ready for processing. Buffer pointers are specified in the info structure.

SND_AUX_REASON_PARAMETERUPDATE
MIDI parameters have been changed. Parameters are stored in the info structure.

SND_AUX_INFO *info
Pointer to an info structure containing data needed to properly react to the reason code passed by the caller. Depending on the code either the fields in the SND_AUX_BUFFERUPDATE structure or in the SND_AUX_PARAMETERUPDATE are valid.

void *userA
Pointer to data structure or other construct needed by the effects algorithm. The reverb, chorus, and delay effects provided by MusyX use this argument as a pointer to a structure which describes the parameters of a particular effect. This argument will be passed to the algorithm associated with the AuxA bus.

u8 midiA
Reserved for future use. (Currently unused)

SND_SEQID seqIDA
Reserved for future use. (Currently unused)

void (*auxB)(u8 reason, SND_AUX__INFO *info, void *user)
Pointer to a function to be called when 5ms worth of data has to be processed for AUX B. NULL deactivates the callback. The parameters are the same as the function for AUX A above.

void *userB
Pointer to data structure or other construct needed by the effects algorithm. The reverb, chorus, and delay effects provided by MusyX use this argument as a pointer to a structure which describes the parameters of a particular effect. This argument will be passed to the algorithm associated with the AuxB bus.

u8 midiB
Reserved for future use. (Currently unused)

SND_SEQID seqIDB
Reserved for future use. (Currently unused)

Output:

None.
