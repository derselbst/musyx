sndSetReceiveMessageCallback

void sndSetReceiveMessageCallback(void (*func) (SND_VOICEID vid, s32 mesg));

Purpose:

Macros controlling sounds may send messages (simple signed 32-bit numbers) to the application to communicate state, etc. In order to receive these messages, the application has to register a callback using this function. The callback will be executed each time a message is sent to the application. The message code is passed as a parameter.

Input:

void(*func)(SND_VOICEID vid, s32 mesg)
Pointer to a function to be called when a message is sent to the applecation. Vid contains the ID of the voice sending the message mesg.

Output:

None.
